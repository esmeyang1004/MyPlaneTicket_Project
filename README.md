智慧跨航空公司機票比價系統
Multi-Flight Fare Comparison Prototype
本專案是一款使用 Python、Streamlit、Pandas 與 ECharts 開發的機票比價互動式原型系統。
系統透過自建航班資料集，模擬旅客查詢不同航空公司、不同航線、不同起降時間與不同票價的情境，並加入海外刷卡手續費與託運行李費用試算，協助使用者比較更接近實際支出的總票價。
此作品主要用來展示我在 產品需求拆解、資料欄位設計、比價邏輯規劃、使用者情境設計與資料視覺化 上的能力。

專案設計背景
在查詢機票時，使用者看到的最低票價不一定代表實際最便宜。
不同航空公司可能會因為以下因素造成最終成本差異：
	• 是否需要加購託運行李
	• 是否需支付海外刷卡手續費
	• 不同航班時間造成的選擇差異
	• 同航線下不同航空公司的票價落差
因此，本系統設計一個簡易的比價原型，讓使用者可以依照出發地、目的地、航空公司與加購條件進行篩選，並透過系統計算出較接近實際支出的票價結果。

核心功能
1. 航班資料查詢與篩選
使用者可以依照出發地與目的地篩選航班資料，系統會顯示符合條件的航空公司、航班代號、起降時間與原始票價。
主要欄位包含：
	• 出發地 Origin
	• 目的地 Destination
	• 航空公司 Airline
	• 航班代號 FlightNo
	• 起飛與抵達時間 DepTime
	• 回程時間 RetTime
	• 原始票價 Price

2. 票價成本加權試算
系統提供額外成本試算功能，協助使用者比較不同航班的實際支出。
目前支援：
	• 海外刷卡手續費試算
	• 託運行李費用加購
	• 原始票價與加權後總票價比較
此功能主要模擬使用者在線上旅遊平台或航空公司官網購票時，可能遇到「票面價格較低，但加購後總成本較高」的情境。

3. 價格分析指標
系統會根據目前篩選結果，自動計算該批航班資料中的價格區間，包含：
	• 最低票價
	• 平均票價
	• 最高票價
這些指標可協助使用者快速掌握目前航線的價格分布，作為是否購票或繼續比較的參考。

4. 航班價格視覺化
本專案使用 Streamlit-ECharts 製作票價比較圖表，將不同航空公司或不同航班方案的票價以圖表呈現。
圖表會協助使用者：
	• 快速比較不同航班價格
	• 找出相對低價的航班
	• 觀察同航線下不同航空公司的票價差異

5. 互動式航班資料表
系統內建互動式資料表，讓使用者可以直接檢視完整航班資料。
透過 Streamlit 的資料呈現元件，使用者可以更直覺地查看不同航班方案的細節。

產品規劃思考
本專案雖然是以模擬資料建立，但在設計上有參考實際旅客查詢機票時的使用情境。
我將需求拆解為三個主要流程：
	1. 使用者輸入或選擇查詢條件
	2. 系統根據條件篩選航班資料
	3. 系統計算加權後總票價，並透過圖表與表格呈現結果
透過這個流程，使用者可以更容易理解不同航空公司之間的票價差異，也能避免只看原始票價而忽略額外成本。

後續可擴充方向
未來若持續優化，本專案可以延伸以下功能：
	• 串接即時航班或票價 API
	• 增加更多票價條件，例如艙等、轉機次數、行李件數
	• 加入排序功能，例如依最低總價、最短飛行時間、最早出發時間排序
	• 增加使用者收藏航班功能
	• 加入歷史價格紀錄，呈現價格變化趨勢
	• 增加不同線上旅遊平台手續費比較

專案角色與學習重點
在本專案中，我負責從需求發想、資料欄位規劃、功能流程設計到 Streamlit 原型實作。
透過這個作品，我練習了：
	• 將使用者痛點轉換為產品功能
	• 設計可查詢與可比較的資料欄位
	• 使用 Python 與 Pandas 進行資料處理
	• 使用 Streamlit 建立互動式產品原型
	• 使用圖表呈現資料分析結果
	• 以產品經理角度思考功能優先順序與後續擴充方向
